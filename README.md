## Selected projects

**Emanat — secure document management platform** · [repo](https://github.com/urolovforever/diplom-ishi-latest)
Graduation thesis: a document exchange platform for religious organizations with role-based access, AES-256 / RSA-4096 end-to-end encryption, and ML-based anomaly detection (Isolation Forest over 15 behavioral features). Django REST Framework, React, Celery, PostgreSQL, Docker Compose (8 services).

**TURKUNIB — Turkic Universities Union** · [repo](https://github.com/urolovforever/turkunib) · [live](https://turkunib.org)
Production website of an international university association: 7-language i18n, student portal, exchange-program applications with two-stage review, quota management. Java Spring Boot, Thymeleaf, MariaDB, Liquibase, Docker.

**SportTahlil — AI sports analysis** · [repo](https://github.com/urolovforever/sport-tahlil) · [live](https://sporttahlil.com)
AI-assisted athletic performance analysis service. Python (FastAPI), OpenAI API, Redis.

Static university merchandise storefront, deployed to GitHub Pages with GitHub Actions.
